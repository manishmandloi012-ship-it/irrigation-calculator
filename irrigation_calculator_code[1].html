Farmer and field details

Shop reference: 1 local bigha = 150 ft × 150 ft = 22,500 sq ft. Conversion used: 1 metre = 3.28 ft. Area-based bigha is an approximation; irregular plots and local measurements can differ.

Standard package quantities

Shop rules: Each 1-bigha package starts with 200 m plain lateral, 7 HDPE pipes, 24 sprinkler sets, and 4 accessory/valve units. Filter is optional when water quality / obstacles make filtration necessary. Each 1-hectare package contains 1,000 m plain lateral, 17 HDPE pipes, 120 sprinkler sets, 1 filter, and 10 accessory/valve units. Accessories and valves are the same line item in this calculator. Selling prices are not built into this calculator.

Field-layout settings

Long run detected: the lengthwise sprinkler count exceeds your selected limit. The calculator automatically splits the length into two sections and updates valves/accessories from the width for each section.

Layout calculations are rough planning estimates only. The HDPE route selector changes the approximate route allowance: edge/end uses the field width, middle uses half the width, and unusual route adds half the run length. Splitting a run automatically doubles the width-based valve/accessory estimate because each section is counted separately. It does not automatically add HDPE. Accessories and valves are one combined line item. In Field Layout and Combined modes, calculate valve/accessory positions from field width only: round width ÷ 30 ft up, counting one side only. Use field length to count sprinkler positions along the run; if that count exceeds the selected limit (9 recommended, 10 optional), automatically split the length into two sections and calculate the width-based valve quantity separately for each section. Extra HDPE remains optional. Enable the separate extra-HDPE checkbox only if an extra route is actually needed. It does not calculate pressure loss, pump capacity, nozzle flow, terrain, pipe diameter, or hydraulic suitability. Confirm pipe routing, pressure, sections, fittings and edge coverage with an experienced installer before sale.
